## summary
It implements ADR-030 Amendment 2, rules 1-3.

1. **Ids by `version`.** `selectTradingIds` takes `positionIds` for `"v2"` and the decoded `clobTokenIds` for `"v1"`, even when both are present.
   - Each of these is refused by name: a missing, null, non-string or unknown version (case-sensitive); the selected field absent, null or of the wrong type; not exactly two ids; non-canonical decimals; equal ids; label mismatches.
   - Each refusal raises `GATEWAY_SERIES_WINDOW_REFUSED`.
2. **`parameters.acceptedProtocolVersions`** is a required, reviewed series parameter in both schema copies. It is part of both hashes, and the mirror test holds them equal. A window whose version is not listed is refused.
   - A config without it is refused at parse, with a message saying what to add; there is no default.
   - **Operators add `"acceptedProtocolVersions": ["v1"]`** under `parameters` of each reviewed series, in both the gateway and trader configs. They make it `["v1","v2"]` before the first V2 window (about 2026-11-02). Changing it changes the series hash and starts a new run.
3. **Condition width.** A 31-byte id is right-padded to 32 bytes for the CLOB read. A 32-byte id is unchanged. Any other width gets no read and is refused. Gamma's form stays the identity.
4. **CLOB `v`** is a refusal-only, labelled cross-check: present and different refuses, absent refuses nothing.
5. **V1 is unchanged.** The judge's verdicts on `series-window.json` match the base's digests.
